# MOMO Portfolio

A responsive bilingual developer portfolio for MOMO / M4I Store.

## Highlights

- Responsive single-page portfolio
- English / Arabic switch with RTL support
- Dark / light theme with saved preference
- Project showcase for MKS Core & Portal, MKS Chat Tracker, M4I Store, and MKS Nexus
- Accessible navigation and reduced-motion support
- No build step required — plain HTML, CSS, and JavaScript
- Ready for GitHub Pages

## Local preview

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

This repository includes a Pages deployment workflow in `.github/workflows/pages.yml`.
Enable **Settings → Pages → Build and deployment → Source: GitHub Actions** once if the repository has not used Pages before.
